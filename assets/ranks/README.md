# Rank icon files

Place the Tanki rank icons in this folder as PNG files named:

```text
01.png  Recruit
02.png  Private
03.png  Gefreiter
...
30.png  Generalissimo
31.png  Legend
```

The tracker reuses `31.png` for Legend 2 and every later Legend level. Recommended size: square PNG, at least 80×80 pixels, with a transparent background.
